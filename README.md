# 🏃‍♂️ Расписание занятий — ФФКиС (1 курс, 1 семестр)

Интерактивное веб-расписание для студентов **Факультета физической культуры и спорта**, направление *«Физическая культура для лиц с отклонениями в состоянии здоровья (адаптивная физическая культура)»*, профиль *«Физическая реабилитация»*.

---

## ✨ Особенности и функционал

- 📱 **Mobile-First дизайн**: Интерфейс оптимизирован под экраны смартфонов, поддержка `safe-area-inset` для современных устройств.
- ⚡ **Hero-виджет текущего статуса**:
  - Отображает текущую пару в реальном времени с прогресс-баром и таймером обратного отсчета до конца пары.
  - Показывает следующую пару и время до её начала.
  - По окончании всех занятий на день подсказывает время и предмет первой пары следующего дня.
- 📅 **Все дни на одном экране**: Вся учебная неделя (Пн–Сб) доступна в виде удобной ленты карточек.
- 🎯 **Автоскролл и подсветка "Сегодня"**: Страница автоматически определяет день недели, подсвечивает его акцентным цветом и плавно скроллит к нему при открытии.
- 📝 **Локальные приватные заметки**:
  - К любой паре можно прикрепить персональную заметку (домашнее задание, дедлайны, что взять с собой).
  - Заметки сохраняются в `localStorage` браузера конкретного пользователя. Каждый студент видит только свои записи.
  - На карточках пар с заметками отображается визуальный индикатор (точка).
- 🎨 **Современный UI**: Тёмная тема, чёткая типографика (Geist), бейджи для лекций (`лк`) и практических занятий (`пр`), цветовая дифференциация типов локаций (аудитории, спортзал, городской стадион).

## 🚀 Размещение на GitHub Pages

Чтобы сайт открывался по прямой ссылке в интернете:

1. Перейдите в настройки репозитория: **Settings** → **Pages**.
2. В разделе **Build and deployment** выберите источник: **Deploy from a branch**.
3. Выберите ветку `main` (или `master`) и папку `/ (root)`.
4. Нажмите **Save**. Ссылка станет доступна через минуту (например: `https://timovar42.github.io/fkis/`).
