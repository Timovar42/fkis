# 🏃‍♂️ Расписание занятий с админ-панелью — ФФКиС (1 курс)

Веб-приложение студенческого расписания для **Факультета физической культуры и спорта**, профиль *«Физическая реабилитация»* с защищённой mobile-first админ-панелью для старосты группы.

---

## 🏗️ Архитектура и стек

- **Frontend:** Чистый HTML5, CSS3 (CSS Variables, Grid, Flexbox), Vanilla JavaScript (ES6+). Без сборщиков, без npm-зависимостей и без фреймворков.
- **Backend / Serverless:** **Cloudflare Pages** + **Pages Functions** (папка `/functions/api`).
- **База данных:** **Cloudflare KV** (`SCHEDULE_KV`) — единая JSON-структура расписания, черновик, аудит и версионирование последних 10 публикаций.
- **Безопасность:**
  - PBKDF2-HMAC-SHA256 с солью для хэширования пароля старосты.
  - Постоянное по времени сравнение (`crypto.subtle.timingSafeEqual`) для защиты от timing-атак.
  - Подписанные HMAC-SHA256 сессионные куки (`HttpOnly`, `Secure`, `SameSite=Strict`, 14 дней).
  - Rate limiting в KV: не более 5 неверных попыток входа с одного IP за 15 минут, одинаковый ответ при любой ошибке.

## 📁 Структура проекта

```text
├── index.html                   # Публичный сайт (загружает /api/schedule, кэш, оффлайн-режим, замены)

│   └── index.html               # Админ-панель (авторизация, блочный редактор, drag & drop, замены, звонки, история)

│   └── api/
│       ├── _utils.js            # Безопасность, PBKDF2, куки, KV-хелперы, валидатор данных
│       ├── schedule.js          # GET /api/schedule (публичный эндпоинт, кэш 60 сек)
│       ├── login.js             # POST /api/login (проверка пароля, rate-limit 5/15 мин, установка сессии)
│       ├── logout.js            # POST /api/logout (сброс сессии)
│       ├── draft.js             # GET /api/draft, PUT /api/draft (автосохранение черновика)
│       ├── publish.js           # POST /api/publish (публикация черновика и архивация в историю)
│       ├── history.js           # GET /api/history (список последних 10 опубликованных версий)
│       └── restore/
│           └── [version].js     # POST /api/restore/:version (откат к выбранной версии)
├── scripts/
│   └── generate-hash.mjs        # Node.js скрипт для генерации PBKDF2 соли, хэша и SESSION_SECRET
└── README.md                    # Руководство по развертыванию и настройке
```

## 🚀 Пошаговое развёртывание в Cloudflare Pages

### Шаг 1. Сгенерируйте хэш пароля и секрет сессии

На вашем компьютере выполните скрипт (подставьте ваш желаемый пароль для входа в админку):

```bash
node scripts/generate-hash.mjs "мой_секретный_пароль_старосты"
```

Скрипт выведет две строки:
```text
ADMIN_PASSWORD_HASH="pbkdf2$100000$..."
SESSION_SECRET="..."
```
Сохраните эти значения.

---

### Шаг 2. Создайте пространство Cloudflare KV

1. Войдите в консоль [Cloudflare Dashboard](https://dash.cloudflare.com/).
2. В левом меню перейдите в **Storage & Databases** → **KV**.
3. Нажмите **Create Namespace**.
4. Введите имя, например: `fkis-schedule-kv`.
5. Нажмите **Add**.

---

### Шаг 3. Создайте проект Cloudflare Pages

1. В левом меню выберите **Workers & Pages** → **Create application** → вкладка **Pages** → **Connect to Git**.
2. Выберите ваш репозиторий `Timovar42/fkis`.
3. Задайте параметры сборки:
   - **Framework preset:** `None`
   - **Build command:** *(оставьте пустым)*
   - **Build output directory:** `/` (или оставьте пустым, если корень)
4. Нажмите **Save and Deploy**.

---

### Шаг 4. Подключите KV и переменные окружения

1. В настройках созданного проекта Pages перейдите в **Settings** → **Functions**.
2. Найдите раздел **KV namespace bindings** и нажмите **Add binding**:
   - **Variable name:** `SCHEDULE_KV` *(именно так, заглавными буквами)*
   - **KV namespace:** выберите созданный на Шаге 2 `fkis-schedule-kv`.
3. Перейдите в **Settings** → **Environment variables**:
   - Нажмите **Add variable** и добавьте переменные для `Production` и `Preview`:
     - Имя: `ADMIN_PASSWORD_HASH`, Значение: `pbkdf2$100000$...` *(из Шага 1)*
     - Имя: `SESSION_SECRET`, Значение: `...` *(из Шага 1)*
4. Нажмите **Save**.
5. Запустите пересборку (вкладка **Deployments** → у последнего деплоя **Manage** → **Retry deployment**), чтобы переменные и KV применились.

## 👩‍💼 Как пользоваться админ-панелью (`/admin/`)

1. Откройте адрес вашего сайта с добавлением `/admin/` (например, `https://fkis.pages.dev/admin/`).
2. Введите пароль и нажмите **«Войти»**.
3. **Редактирование расписания (вкладка «Неделя»):**
   - Нажмите на любую ячейку, чтобы выбрать предмет из списка, создать новый или очистить слот.
   - Используйте кнопки со стрелками **«Выше»** / **«Ниже»** или перетаскивайте карточки пальцем/мышью — при перетаскивании на занятую пару карточки автоматически меняются местами.
   - Кнопка «Дублировать» позволяет быстро скопировать пару в другой день.
4. **Вкладка «Предметы»:**
   - Изменение аудитории, корпуса, преподавателя и типа (лк/пр). Изменение предмета автоматически обновляет его во всех ячейках расписания.
   - Удаление предмета с защитой и предупреждением о количестве занятых пар.
5. **Вкладка «Замены» (разовые отмены и замены):**
   - Укажите дату, номер пары и выберите действие (*«Отменить пару»* или *«Заменить на другой предмет»*).
   - Заметка к замене («преподаватель на больничном») сразу отобразится у студентов. После наступления следующего дня замена исчезает автоматически.
6. **Вкладка «Звонки»:**
   - Корректировка времени начала и конца 4 пар.
7. **Публикация изменений:**
   - Все правки автоматически сохраняются в черновик.
   - Кнопка **«Предпросмотр»** позволяет увидеть сайт глазами студентов до публикации.
   - Кнопка **«Опубликовать»** применяет изменения на живой сайт и создаёт точку восстановления.
   - Кнопки **«Отменить» (Undo)** и **«Повторить» (Redo)** поддерживают до 25 последних действий прямо в браузере.

## ⏪ Как откатить версию (восстановление из истории)

1. Откройте в админке вкладку **«История»**.
2. В списке отображаются последние 10 опубликованных версий с датой и временем.
3. Нажмите кнопку **«Вернуть»** напротив нужной версии.
4. Данные загрузятся в ваш черновик — проверьте их и нажмите **«Опубликовать»**.

---

## 🔑 Как сменить пароль старосты

1. Сгенерируйте новый хэш с новым паролем:
   ```bash
   node scripts/generate-hash.mjs "новый_пароль"
   ```
2. В панели Cloudflare Pages откройте **Settings** → **Environment variables**.
3. Обновите значение `ADMIN_PASSWORD_HASH` на новое.
4. Сохраните. Пароль обновится мгновенно без повторного билда.
